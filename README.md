# 微信小程序炸弹大作战游戏

一个基于微信小程序的实时对战炸弹游戏，支持双人在线对战，具有精美的UI设计和流畅的游戏体验。

## 🎮 游戏特色

- **5×4网格对战**: 在20个格子的战场上展开智慧对决
- **实时多人对战**: 基于WebSocket的实时通信
- **精美UI设计**: 使用微信表情包，界面美观大气
- **完整游戏流程**: 设置→对战→结果，体验完整
- **智能计时系统**: 60秒设置时间，90秒对战时间
- **爆炸特效**: 炸弹爆炸时的震撼视觉效果

## 🚀 游戏玩法

### 基本规则
1. **房间创建**: 玩家可以创建房间或通过房间号加入游戏
2. **炸弹设置**: 双方各自在5×4网格中选择一个位置放置炸弹（60秒限时）
3. **轮流对战**: 玩家轮流选择格子，每回合90秒限时
4. **确认机制**: 选择格子后必须点击确认按钮才生效
5. **胜负判定**: 点击到对方炸弹位置即获胜
6. **重新开始**: 游戏结束后可选择重来或退出

### 游戏阶段
- **设置阶段**: 60秒内选择炸弹位置，超时自动随机选择
- **对战阶段**: 轮流选择格子，每回合90秒限时
- **结果阶段**: 显示胜负结果，60秒内选择后续操作

## 🛠️ 开发环境搭建

### 前置要求
- 微信开发者工具
- 微信小程序账号
- 微信云开发环境

### 安装步骤

1. **下载项目**
   ```bash
   git clone [项目地址]
   cd bomb-game
   ```

2. **配置微信开发者工具**
   - 打开微信开发者工具
   - 导入项目，选择项目根目录
   - 填入你的小程序AppID

3. **配置云开发环境**
   - 在微信开发者工具中开通云开发
   - 创建云开发环境
   - 修改 `app.js` 中的环境ID

4. **部署云函数**
   - 右键点击 `cloudfunctions` 目录
   - 选择"上传并部署：云端安装依赖"
   - 分别部署所有云函数

5. **配置数据库**
   - 在云开发控制台创建以下集合：
     - `gameRooms`: 游戏房间数据
     - `games`: 游戏数据

6. **配置WebSocket**
   - 根据需要配置WebSocket服务器
   - 修改 `app.js` 中的WebSocket连接地址

## 🎯 核心功能实现

### 房间管理
- 创建房间：生成唯一房间号
- 加入房间：通过房间号或分享链接
- 房间状态：等待、游戏中、已结束
- 玩家管理：房主权限、准备状态

### 游戏逻辑
- 网格系统：5×4共20个格子
- 炸弹设置：隐藏式设置，对手不可见
- 回合制：轮流选择，确认机制
- 胜负判定：点中炸弹即分胜负

### 实时通信
- WebSocket连接：实时同步游戏状态
- 消息类型：加入房间、游戏操作、状态更新
- 断线重连：自动重连机制
- 状态同步：确保双方数据一致

### UI/UX设计
- 响应式设计：适配不同屏幕尺寸
- 动画效果：流畅的过渡动画
- 表情包集成：使用微信表情包
- 视觉反馈：点击、爆炸等特效
